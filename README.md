**Gobble Run — The Great Thanksgiving Getaway.** Waddles the turkey has seen the menu, and he *is* the menu. A complete, original canvas runner: outrun Farmer Brown for 1,200 m — from the farmyard, through the pumpkin patch, past the farmhouse kitchen yard — to the safety of the woods. Jump hay bales, fences, pitchforks, glowing ovens and fully set dinner tables; duck the flying carving knives; grab corn (+50) and pumpkin pie (+150 and a life). Three lives, near-miss bonuses, a farmer who surges every time you stumble and can be heard shouting about it, parallax sunset art, squash-and-stretch animation, particles, screen shake and a fully synthesised WebAudio soundtrack. Title screen, HUD (score, distance, lives, farmer meter), pause, and caught/escaped end screens with restart. Keyboard (arrows / WASD / Space, P pause, M mute) and mouse (click to jump, hold low to duck, clickable buttons). Plain static files under `game/`, no build step, no network — it plays offline in a desktop browser.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
